# SuperFly Homebrew tap

[Homebrew](https://brew.sh) formulas for SuperFly software, on macOS (Apple Silicon) and Linux.

## SuperFly Manager

```sh
brew install superflytv/tap/sfm
```

Update with `brew upgrade sfm`. Then see the [documentation](https://docs.superfly.tv/html-engine) to get started.

Other downloads, including Windows, are on [SuperFly-releases](https://github.com/SuperFlyTV/SuperFly-releases).

The formulas are written by each product's release pipeline: changes made here are overwritten by the next release.
